# v1.8.0 发布说明

- 公告支持独立草稿、定时发布、开始显示及截止时间，统一 UTC+8；更新和普通公告各取最新有效一条，更新优先。日期截止包含当天，到期后仍保留信箱历史。
- 增加黑名单列表与解除入口，以及账号注销、学校邮箱解绑。两种账号操作通过邮箱验证码验证并明确提示影响；注销立即生效，原内容匿名保留，重新注册不继承旧数据，邮箱冷却一小时。管理员和超管禁止注销、绑定和解绑。
- 增加建议与反馈，用户可查看记录、状态和全部回复；仅超管可以管理、导出和导入 CSV。反馈编号准确匹配，逐行处理有效记录并报告错误，已完成归档后不再默认导出。
- 私聊复制／举报收进消息操作菜单，举报只提交选中的消息；超级管理员可以从目录详情快捷管理资料和图片。
- 帖子详情显示浏览量，同次打开的重试去重，评论、点赞和刷新不重复累计。

- 全站使用自托管 Google 风格平面彩色 Emoji，修复公告带框数字等组合表情；普通数字保持正文字体。
- 社区多图跟手滑动与平滑停靠；账号变更、旧响应和失败重试按当前身份处理。
- 下载页同步通过 main CI 与 Android CD 发布的 v1.8.0 正式签名 APK、SHA-256、来源信息和经重建校验的增量补丁。

本次只发布构建包，不部署线上服务器。部署时先升级 Backend v1.8.0（V43–V46），再更新 Web 与 Android；用户实机验收仍可补充。
