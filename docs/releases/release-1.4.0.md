# v1.4.0 发布说明

前端版本更新为 `1.4.0`，与 Backend / Android `v1.4.0` 同步。

## 更新范围

- **社区互动消息**：信箱系统消息区分食记点赞、评论点赞、食记评论与评论回复，展示聚合人数；点击可跳转原帖并按需加载分页定位楼层/回复。
- **私信**：通知信箱新增「私信」标签，展示会话、最后消息与未读；新增聊天页（加载更早、轮询新消息、自动已读、发送与隐藏）；社区作者栏提供快捷「私信」。
- **增量页面刷新**：食堂、档口、菜品、个人资料与信箱按区域刷新，保留静态内容与输入状态；跨账号切换会清理异步缓存。
- **下载页**：发布签名 APK 后更新 `public/downloads`（APK、`.sha256`、`manifest.json`）与 `download.js` 元数据。

## 发布顺序

1. Backend 合并并部署（V39/V40）；
2. Android 合并 `dev → main`，等待 CD 产出签名 APK 与 `manifest.json`；
3. 用该 APK 更新 `public/downloads` 后合并本仓库 `develop → main`。

## 安全

- 私人数据不再写入异步缓存之外的持久层；登录/登出/角色变化会清空缓存。
- 前端不使用原始 HTML 渲染用户内容；公告 Markdown 仍经 DOMPurify 清洗。
