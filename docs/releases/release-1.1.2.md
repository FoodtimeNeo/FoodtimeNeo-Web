# v1.1.2 发布说明

Web 项目版本为 `1.1.2`，使用 `develop → main` 发布 PR。

## 更新范围

- API 请求统一携带官方客户端标识头。
- 点评正文与简介输入增加 500 字限制。
- 移除食堂轮播的 scroll-snap 自动吸附，并保留划动提示。

## Android 下载文件

当前仓库内下载文件仍为已验证的 Android `v1.1.1`（versionCode `6`），下载常量、校验文件和来源记录保持与实际 APK 一致。

Android `v1.1.2` 正式 Release 生成后，需替换 APK，并同步 SHA-256、来源记录、下载常量及相关测试。不能仅修改元数据将旧 APK 标记为新版本。

## 发布要求

合并前运行 `npm run check`。本地准备不能替代远程最新状态检查、CI 或实际部署。
