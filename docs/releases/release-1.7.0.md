# v1.7.0 发布说明

- 支持跨食堂搜菜和收藏菜品。发帖时可在同一表单内按食堂、档口、菜品逐级筛选和关联。
- 社区提供关注、发现、收藏和我的食记四个分类，支持跟手横滑和下拉刷新。各分类有自己的页首说明。
- 增加作者主页、内容举报和私信拉黑，完善私信未读同步与帖子分享直达。

下载页分发 [Android v1.7.0 正式签名包](https://github.com/FoodtimeNeo/FoodtimeNeo-Android/releases/tag/v1.7.0)。APK、SHA-256、来源记录和增量升级清单一并放在 `public/downloads`。

部署时先升级 Backend v1.7.0，再部署 Web 构建制品并启用客户端升级提示。
