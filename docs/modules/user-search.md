# 搜索用户

信箱、关注及粉丝列表提供“搜索用户”入口，登录后访问 `/users/search`。用户名使用现有昵称，不搜索邮箱。每行展示头像、完整昵称、“关注／已关注”和“私信”按钮，沿用设计令牌和现有按钮、媒体组件。

关键词最多 50 个字符，停顿 300ms 自动搜索，也可回车或点“搜索”。空输入不请求。调用 `GET /api/v1/users/search?q=...&page=1&size=20`，响应为 `items/total/page/size`，每行仅 `id/displayName/avatarUrl/followedByMe`。后端按完整、前缀、包含匹配依次排序，排除本人和停用用户。

`usePagedData` 管理分页、取消和过期请求；输入框与页面入口保留，只有结果区域展示加载、失败重试、无匹配及分页。关注写入成功只更新该行标志，不重搜列表。私信复用现有开始会话接口后进入聊天页，不自动发消息。

`useUserSearchStore` 仅在内存保存关键词，按用户及角色隔离；从聊天返回恢复关键词并重新读取第一页。换号、角色变化和退出时清除。访客可以搜索，行操作禁用并提示绑定学校邮箱；服务端仍负责最终授权。

行为回归见 `UserSearchView.spec.js`、`useUserSearchStore.spec.js`，覆盖防抖、取消迟到结果、分页、空态与错误、关注局部更新、打开私信和身份隔离。完整门禁仍为 `npm run check`。
