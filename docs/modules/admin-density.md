# 管理页单列紧凑布局

2026-11-03，基于 `develop` 的 `da9eef5`，在 `feature/admin-density` 实现用户选定的“原布局·单列紧凑”方案。

## 页面与交互

- 保留网站导航、面包屑、横向管理导航、纸张风格及单列卡片。仅管理外壳启用紧凑模式，公共页面保持原有间距。
- 内容审核：标题、类型／状态按钮、卡片与操作区减少留白；发布者名称、邮箱、ID、发布时间在宽屏并排展示，窄屏单列换行。列表正文最多两行，配图使用缩略图，AI 展示风险、置信度、标签及建议摘要。完整内容入口保留全文、图片浏览、完整 AI 诊断及审核确认表单。
- 内容管理：目录类型、所属筛选与新增操作集中到现有页面的筛选区域。目录简介默认两行，可展开全文；封面缩略图可打开大图。保留卡片内编辑、新增全部字段、删除确认和错误反馈。所属筛选在只有一页时隐藏无用分页，多页时保留翻页。
- 审核日志：保留日志 ID、投稿 ID、发布者资料、发布时间、审核人／AI 模型、审核时间；列表中的正文及审核原因最多两行，点击“查看完整日志”展示完整内容和配图。弹窗底部的关闭操作固定，长内容在弹窗正文内滚动。
- 分页接口及每页 20 条保持现状；本轮没有增加搜索、排序或服务端筛选接口。

## 边界与修复

管理员和超级管理员保留现有权限；移动端按钮和管理导航至少 44px 高，桌面精确指针下列表按钮为 36px。全部用户内容继续使用文本插值展示。

同时修复餐厅／档口点评详情缺少社区对象时覆盖发布者资料的问题，并在这些详情加载失败时禁用弹窗中的审核操作；提交前完整详情校验继续保留。

## 验证

完整门禁：`npm run check`（ESLint、Prettier、Vitest、生产构建）。新增回归覆盖点评详情发布者资料、完整 AI 信息、文本转义、日志展开／关闭与字段保留，以及详情失败时不能发起审核。

浏览器连接本地后端验证审核状态／类型筛选、完整详情、日志展开／关闭与真实分页、目录卡片内编辑、封面大图。375px 窄屏验证三个页面、长 ID 换行和弹窗底部操作，无横向溢出。浏览器验证使用本地已有验收记录；没有向云端写入数据。
