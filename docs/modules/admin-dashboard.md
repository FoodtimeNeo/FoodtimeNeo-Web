# 平台数据看板

路由 `/superadmin/analytics` 仅向 superadmin 开放，读取 `GET /api/v1/admin/dashboard?days=7` 的真实 `.data`，失败不再回退样例数据。后端权限校验仍是最终边界。

- 8 项累计：有效用户、正式点评、正式回复、已发布食记、启用食堂/档口/菜品、最近 5 分钟已认证请求的去重在线用户。
- 趋势：含当日的最近 7 个连续自然日，按 Asia/Shanghai 聚合；横轴直接使用 YYYY-MM-DD，不受浏览器时区影响。
- 点评互动为投稿与回复之和；新点评、新食记含待审等创建记录，累计仅计正式内容，两种口径在页面说明。
- `onlinePeak` 保留后端兼容字段名，界面统一为“日活用户”，指当日行为去重人数，不能解释为并发峰值。
- `generatedAt` 显示为北京时间。进入页面、恢复可见和手动刷新重新读取；切换趋势只使用快照，无轮询。
- 首次失败显示错误及重试；后续网络/服务异常保留上次数据并提示。401/403、换号、降权和卸载页面清除数据、取消请求；迟到响应不得回填新账号。
- 对整数计数、时间、日期连续性和趋势长度进行校验。缺失和异常值不补零，不生成示例快照。
- 平滑曲线的控制点限制在相邻真实点范围内，避免非负统计出现负数曲线。
