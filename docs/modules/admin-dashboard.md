# 平台数据看板

路由 `/superadmin/analytics` 仅向 superadmin 开放，读取 `GET /api/v1/admin/dashboard?days=30` 的真实 `.data`，不回退样例数据。后端权限校验仍是最终边界。

- 顶部并排展示“总用户量”与“当前在线”。总用户量为全部注册账号，含停用账号；保留“有效用户”指标，仅统计启用账号。总用户量卡片采用普通边框。
- 平台总览保留有效用户、正式点评、正式回复、已发布食记、启用食堂/档口/菜品和在线用户 8 项当前指标。
- 默认近 7 日，支持近 30 日。一次读取完整 30 日快照，周期与指标切换均在本地完成，不额外请求，累计与实时数据保持原口径。
- 趋势新增“用户总量”，读取服务端 `trend[].totalUsers`；其余为新增用户、评论互动、社区食记、日活用户。按 Asia/Shanghai 聚合，含今日，横轴直接使用服务端业务日期。图表按实际宽度布局，30 日减少刻度和常驻数值标签，可通过键盘聚焦或点击数据点查看每日数据。
- 新增汇总固定显示“今日新增 / 近 7 日新增 / 近 30 日新增”三列，分别汇总快照末 1、7、30 日的注册、点评投稿、回复和食记创建数，与趋势周期独立。
- 点评互动为投稿与回复之和；新点评、新食记含待审等创建记录，累计仅计正式内容，页面显示口径说明。
- `onlinePeak` 保留兼容字段名，界面显示“日活用户”，指当日行为去重人数。
- `generatedAt` 按北京时间显示。进入页面、恢复可见和手动刷新重新读取；刷新保留所选周期与指标，无轮询。
- 首次失败显示错误及重试；后续网络/服务故障保留上次数据并提示。401/403、换号、降权与卸载清除数据并取消请求，迟到响应不得回填新账号。
- 校验整数计数、时间、日期连续性和趋势长度，并验证总用户量不小于有效用户数、逐日累计与新增一致、末日累计与当前总量一致。缺失或异常值不补零，不拼接不同请求的快照。
- 沿用纸张风格，正文、辅助文字、选中指标与表格使用深棕色，曲线保留指标色。支持 320px 窄屏及减少动态效果设置。

## 验证

`npm run check` 执行 ESLint、Prettier、Vitest 和生产构建。回归覆盖 30 日数据校验、双周期切换、三列新增汇总、键盘和点击查看数据、刷新保留选择、旧快照提示、权限清理和迟到请求隔离。真实浏览器联调仅使用隔离本地后端及数据库。
