# 校园食堂地图

路由 `/canteens/map`，从食堂列表进入。需要正常登录，沿用现有路由守卫，不增加第三方地图 SDK 或定位权限。

底图与区域来自用户提供的 5032×3579 校方手绘地图，图上署北京交通大学招生办公室，2023 年 6 月更新。左下角非地图内容已清理，来源信息保留在此说明。WebP 为同尺寸编码版本，按需加载，不进入首页首包。

`src/assets/campus-map/regions.json` 保存图像坐标、区域 ID 与目录 ID；与底图版本一起维护。不是经纬度数据。六处区域：明湖、学活／主区清真／西餐、留园、学四、东区学生餐厅、益民。教工、学苑及东区清真按用户要求暂不标注。

支持缩放、拖动、键盘／名称选择。点选后仅从实时食堂列表显示已关联且可用的详情入口；同楼多层分别进入。没有目录关联、目录停用、入口读取失败均明确显示，地图仍可使用；失败可重试。当前不显示 GPS 定位、不生成步行路线或测距。

修改位置只调整独立区域数据；增删目录关联不应重绘底图或把地图类型加入目录 API。未来路线网须独立维护、实地确认，不能用直线冒充可行路线。

验证：地图几何与目录单测；Chromium／Windows WebKit 390、820、1440px 共 48 项实际页面检查，含坐标点选、拖动、键盘、失败重试。接口使用本地受控 HTTP；不是线上或 Apple Simulator 验收。
