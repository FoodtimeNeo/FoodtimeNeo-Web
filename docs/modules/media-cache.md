# 图片加载与缓存

## 看图操作

全屏底部分享、评论和赞使用 28px 矢量图标、默认至少 16px 的文字与至少 76px 高的操作区；字号随根字号放大，三项保留间距，长计数换行而不挤压图标。原有分享／评论／点赞事件、选中及忙碌状态保持。手机、窄屏大字体、桌面和横屏均检查。

触屏通过左右滑动切换图片，帖子内保留页码和可点击指示点；全屏右上角“看图选项”提供上一张／下一张，首尾禁用对应操作。触屏不常驻两侧箭头；有精确指针和悬停能力的设备在悬停或键盘聚焦时显示翻页控件，帖子内控件使用纸张／描边风格。窄屏也可使用鼠标与键盘，不按屏幕宽度判断输入方式。

全屏支持左右方向键、缩放键和 Esc；菜单展开时 Esc 先收起菜单并恢复其焦点，再按才关闭看图。顶部操作按独立列布局，预留间距，避免原图、页码与选项重叠。翻页方式调整不改变媒体可见性、请求和缓存规则。

`MediaImage`统一目录、社区、头像和审核图片入口。列表及社区详情轮播使用480px缩略图，社区轮播仅创建当前及至多后一张的加载器，节流网络不预取。社区全屏也从当前缩略图开始，点击“加载原图”才请求该张原图。菜品图册继续按其原图规则加载。

图片字节交给浏览器HTTP缓存管理；应用只持有当前展示的Blob URL和在途请求。新展示先校验私有媒体，服务端明确返回公开不可变策略后允许新鲜缓存直接复用。退出、切号、页面恢复和路由切换释放旧引用、取消旧请求；no-store预览不跨展示复用。缓存清理不会清除信箱水位或登录凭据。

`/sw.js`保留为迁移入口，激活后清除旧的`foodtime-media-*`CacheStorage，不再拦截媒体。同站媒体请求前通过消息确认新Worker策略，控制器更换后重新确认，避免升级瞬间仍从旧Cache-First Worker读出图片。浏览器原生HTTP缓存的容量与回收由浏览器决定。
