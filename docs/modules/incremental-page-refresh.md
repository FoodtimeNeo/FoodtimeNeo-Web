# 页面按区域加载与刷新

页面保持原有布局和样式。固定导航、标题、功能入口不等待无关读取；动态区域分别维护加载、错误与重试。

- `useAsyncData.loading` 表示在途请求，`initialLoading` 只表示尚无成功内容的首次加载。后台刷新保留已有数据，分页按钮仍使用 `loading` 防止重复操作。
- 目录快照只放在内存中，返回页面先显示已有内容，同时以 `ttl: 0` 向服务端重新校验。退出、切号、角色变化清理缓存；清理前的在途响应不能重新写回。401、403、404 会撤下对应旧内容。
- 食堂基础信息与档口列表分别读取。档口名称就绪即显示，再加载菜单。菜品基础信息校验所属关系后，图片、评分各自读取；评论独立分页。局部重试不重新读取其他区域。
- 个人页固定功能入口独立于资料请求。信箱只加载当前标签的列表，另外读取标签所需未读计数；已加载标签切换时复用当前页。标记已读使用服务端确认更新原消息，不重新加载列表。

验收覆盖慢图、评分失败后局部重试、静态入口可用、信箱请求次数、已读后 DOM 保留，以及身份切换和页面离开时的迟到响应。统一门禁为 `npm run check`；真实浏览器验证使用工作区 `test/` 下的本地隔离环境。
