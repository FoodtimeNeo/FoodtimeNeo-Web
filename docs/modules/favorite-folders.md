# 帖子收藏夹分层

进入帖子收藏先展示收藏夹目录，包含“全部”“默认分组”和本人自建收藏夹；点进后才加载夹内公开帖子。“全部”不传分组条件，默认分组使用unfiled，自建夹传groupId，保留原分页与服务端账号/可见性校验。

目录保留新建入口，返回与浏览器后退回到目录。移除常驻大条刷新按钮，目录和夹内均保留原有手势刷新；夹内刷新保留当前夹，不切回全部。加载失败提供局部重试，空夹保留空态。分组和帖子属于本人数据，不进入公开目录缓存。

Web使用folder路由参数保存层级，丢弃切换收藏夹、账号或返回后的迟到结果；Android使用独立community-favorite-folder页面栈和原RefreshScrollView组件。Web709项完整检查及实际浏览器导航/手势通过；Android225 JVM与136项模拟器检查通过。未合main、未改版本或部署。
