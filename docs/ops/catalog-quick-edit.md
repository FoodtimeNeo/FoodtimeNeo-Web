# 详情页快捷管理

超级管理员在食堂、档口、菜品详情中可直接打开「管理食堂 / 档口 / 菜品」。弹窗复用目录编辑表单，并提供分页图片管理，无需重新寻找后台记录。普通用户和普通管理员不显示此入口，服务端继续检查全部权限。

添加使用本人上传的图片，失败重试复用上传引用；移除需要确认，只移除当前目录关联，档口封面与图集同步处理。图片更新局部刷新图片；停用或删除目录成功后返回上级页面。有关联数据时删除失败，面板保留原因，可选择停用。

接口：原 `/admin/catalog/{type}/{id}` 负责编辑和删除目录；新增 `/admin/catalog/{type}/{id}/images` 负责分页读取、添加，`DELETE .../images/{imageId}` 负责移除。图片列表每页 12 张。
