# 1.0.0 发布验收

本次按三端统一版本要求，将 package.json 和锁文件版本设为 1.0.0；历史发布记录保留。

- FT-01：首页食堂没有有效评分时显示“无评分”，不再填入固定 4.5；真实评分保留一位小数。
- FT-02：社区图片指示按钮在窄屏自动换行，维持 44×44px 点击区，增加当前图片页码。
- FT-03：提交评论、楼内回复后保留已加载评论及已展开回复；刷新相同图片列表不会重置图片位置和放大层。跨帖迟到的提交结果不会清空新帖草稿。

每个问题从最新 develop 单独创建 feature 分支，验证后推送，并用合并节点集成回 develop。发布从 develop 向 main 发起 PR。

## 验证结果

`npm run check` 全部通过：ESLint、Prettier、61 个文件的 252 项 Vitest 测试、Vite 生产构建。新增用例覆盖缺失评分、九图切换、键盘和触摸、图片身份刷新、长讨论游标、超过100条评论的分批刷新及跨帖请求。

真实本地 Backend 页面验收：

- 首页空白食堂显示“无评分”。
- 320、375、390、768px 下，九个图片按钮均位于容器内，没有横向页面溢出；首图和末图均可选择。
- 390px 下加载全部32个一级楼层，选择第九张图片，提交楼内回复后32楼仍保留；展开目标楼全部回复再次提交，回复从6条增加到7条，第九张保持选中，待审核内容仅本人可见。

截图、布局测量及原始检查日志保存在联合工作区 `qa/release-1.0.0/`。该记录证明本地集成环境的结果；main 合并不包含生产服务器部署。完整社区功能依赖 Backend V19–V23 迁移及对应接口。
