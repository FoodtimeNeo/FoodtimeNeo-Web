# Web 接入验收

2026-10-15，范围为现有 Backend 支持的浏览、评分评论、投稿、个人记录和管理闭环。只修改 Web，不修改 Backend/Android 源码或新增数据库模型。以现有 Backend 的 API 文档、DTO、服务逻辑和数据库设计核对字段。未支持入口隐藏；邮箱真实投递按负责人要求暂不验证。

## 自动检查

最终业务代码通过 `npm run check`：ESLint、Prettier、38 个测试文件中的 143 项单元测试，以及生产构建。替换旧接口测试后，删除了针对不存在功能和字段的旧断言。当前测试包含实际字段投影、权限守卫、CSRF 与会话轮换、迟到响应、失败保留输入、分页、父级关系、零/空价格及重复提交处理。测试中的接口替身不参与实际运行。

## 浏览器联调

使用经确认的原隔离数据库和三个样例账号，Web 为 localhost:3000，原 Backend 程序为本机 18080。真实浏览器验证：

- Cookie 登录、刷新后恢复身份、服务端退出及三个实际角色。
- 食堂 → 档口 → 菜品 → 图册与完整父级 URL。
- 点评先进入 pending，审核通过后才显示；HTML 字符按文本展示。
- 真实 PNG 选择、预览、上传、图片投稿、个人 pending 记录及审核通过后的详情图片。
- 个人身份、四类投稿历史、审核状态、历史时间和驳回原因。
- 管理员审核点评和图片，真实日志包含投稿、操作者、时间及说明。
- 独立停用食堂的创建、详情回读和排序编辑。
- 平台管理员用户字段、邮箱搜索、正式评论计数，以及自身权限按钮禁用。
- 375px 视口的详情与管理筛选无横向溢出；详情间距和评论时间已修正。

## 隔离库接口验收

使用同站 Web 代理和实际 Cookie/CSRF，在原隔离库完成 11 组验收：

1. 匿名无会话拒绝、普通用户与管理员无用户管理权限。
2. 缺少 CSRF 的写请求拒绝。
3. 私有图片上传、图片驳回原因与审核时间回读。
4. 空参考价格菜品必须补价；零价有效；重复审核返回冲突。
5. 无 floor 的档口投稿、批准记录及真实父级。
6. 点评批准、本人删除、管理删除原因必填。
7. 关联目录删除被 RESTRICT 拒绝，停用后无法浏览。
8. 禁用样例账号后旧会话失效，恢复后重新登录。
9. 改密后其他旧会话失效。
10. 降级角色立即影响旧会话；非作者普通用户无法读取私有图片或投稿他人引用。
11. 禁止修改自身权限，实际审核日志只有 approve/reject。

测试只操作本轮创建的内容和已授权隔离样例账号，结束时恢复样例账号权限与密码；新建目录验收对象停用保存。没有删除此前验收数据。运行记录和截图留在被 Git 忽略的本地验收目录，未提交 Cookie、真实凭据或测试进程配置。

## 菜品附属点评入口

2026-10-15：移除桌面和移动导航中的独立点评选项，删除三级目标选择器。新地址为 `/canteens/:canteenId/stalls/:stallId/dishes/:dishId/reviews/new`；通过菜品详情校验父级关系，显示当前菜品的实际名称和归属，只填写评分与正文。面包屑、返回、取消及提交成功均保留原菜品参数；加载失败或归属不符时不开放表单。旧独立 `/reviews/new` 地址不再匹配业务路由。

完整门禁通过 143 项测试，覆盖固定目标、忽略查询参数、父级冲突、失败与重试、提交校验、重复写入防护和离开页面后的迟到响应。真实浏览器从食堂 → 档口 → 无图示例菜品进入表单，刷新后目标保持，提交 4 星和正文后返回该菜品；个人记录确认同一菜品的 pending 点评。375px 视口确认三个底部导航项、无目标选择器、无横向溢出，以及取消返回原菜品。

## 实际限制

注册邮件尚未正式接通，页面显示后端返回的发送错误，不绕过验证码。评分读取后端每日物化快照，审核或删除后不会由前端立即重算。生产部署需 HTTPS 与同站 API 反向代理；本轮交付开发代码与本地联调环境，不包含生产部署。
