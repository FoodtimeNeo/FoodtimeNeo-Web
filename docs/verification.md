## 隔离库接口验收

使用同站 Web 代理和实际 Cookie/CSRF，在原隔离库完成 11 组验收：

1. 匿名无会话拒绝、普通用户与管理员无用户管理权限。
2. 缺少 CSRF 的写请求拒绝。
3. 私有图片上传、图片驳回原因与审核时间回读。
4. 空参考价格菜品必须补价；零价有效；重复审核返回冲突。
5. 无 floor 的档口投稿、批准记录及真实父级。
6. 点评批准、本人删除、管理删除原因必填。
7. 关联目录删除被 RESTRICT 拒绝，停用后无法浏览。
8. 禁用样例账号后旧会话失效，恢复后重新登录。
9. 改密后其他旧会话失效。
10. 降级角色立即影响旧会话；非作者普通用户无法读取私有图片或投稿他人引用。
11. 禁止修改自身权限，实际审核日志只有 approve/reject。

测试只操作本轮创建的内容和已授权隔离样例账号，结束时恢复样例账号权限与密码；新建目录验收对象停用保存。没有删除此前验收数据。运行记录和截图留在被 Git 忽略的本地验收目录，未提交 Cookie、真实凭据或测试进程配置。
