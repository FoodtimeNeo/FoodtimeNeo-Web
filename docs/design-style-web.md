# FoodtimeNeo-Web 前端设计风格规范

本文档以 `FoodTime--frontend` 的视觉规范为基线，约束 `FoodtimeNeo-Web`（北交干饭吧）的视觉与交互设计，包括色彩、字体、间距、形状、阴影、装饰、组件、动效、响应式和无障碍要求。新项目保持原有视觉语言，页面层级和组件结构以[当前架构](architecture.md)为准。

令牌的唯一来源：

- [src/assets/styles/tokens.scss](../src/assets/styles/tokens.scss)：全部 CSS 变量（颜色、字号、间距、圆角、阴影、装饰素材）
- [src/assets/styles/global.scss](../src/assets/styles/global.scss)：全局基础样式和通用类（`.section-title`、`.button-ink`、`.stamp`、`.sticker` 等）
- [src/App.vue](../src/App.vue)：按路由选择外壳并创建页面
- [src/layouts/DefaultLayout.vue](../src/layouts/DefaultLayout.vue)：普通页面外壳、纸张背景、桌面装饰及主内容容器

本文档与令牌文件冲突时，以令牌文件为准，并同步更新本文档。

## 1. 风格定位

关键词：食堂手账、zine 拼贴、牛皮纸、印章、纸胶带、手写批注。

- 整体像一本摊在牛皮纸桌面上的手账：页面是米白纸张，内容是贴上去的卡片、贴纸和盖上去的印章。
- 视觉语言靠“硬边 + 实色投影 + 轻微旋转 + 正片叠底”建立，不用毛玻璃、大圆角、柔和渐变阴影这类通用 SaaS 风格。
- 桌面端保留完整手账感；移动端（≤768px）改为 App 化：顶部轻量、底部 Tab 导航、去掉旋转和多数装饰，信息分层优先。
- 装饰服务于内容。任何装饰元素都不能遮挡文字、抢占点击区域或造成横向溢出。

### 2.2 用色比例

- 纸张色（牛皮纸 + 米白卡片）约占 70%，墨棕（文字、描边、投影）约 20%，朱红 + 印章色合计不超过 10%。
- 每屏只保留一个朱红实底主操作。其余操作用描边按钮或手写链接。
- 印章蓝是唯一的冷色，只用于印章、日期和信息提示，不作为大面积背景。
- 金银铜只用于排名，不挪作他用。

### 2.3 对比度

按 WCAG 2.x 公式估算的对比度（实际以工具测量为准）：

| 前景 / 背景                         | 对比度    | 结论                                 |
| ----------------------------------- | --------- | ------------------------------------ |
| `#3a2418` 正文 / `#fffaf0` 卡片     | 约 13.9:1 | 任意字号可用                         |
| `#3a2418` 正文 / `#d8c08b` 牛皮纸   | 约 8.2:1  | 任意字号可用                         |
| `#6e5547` 辅助 / `#fffaf0` 卡片     | 约 6.6:1  | 可用                                 |
| `#6e5547` 辅助 / `#d8c08b` 牛皮纸   | 约 3.9:1  | 仅限 ≥18px 或粗体 ≥14px              |
| `#c9341e` 朱红 / `#fffaf0` 卡片     | 约 5.0:1  | 可用                                 |
| `#fff5f2` 文字 / `#c9341e` 朱红按钮 | 约 4.9:1  | 可用                                 |
| `#3f7291` 印章蓝 / `#fffaf0`        | 约 5.0:1  | 可用                                 |
| `#5b7a3a` 橄榄绿 / `#fffaf0`        | 约 4.7:1  | 可用                                 |
| `#b88924` 金 / `#fffaf0`            | 约 3.0:1  | 只能做描边、图形或大字号，不能做小字 |

规则：

- 辅助色文字只放在米白卡片上，不直接放在牛皮纸桌面上。
- 金、银、铜色不承载小字号文字；需要文字时用墨棕文字配 `-soft` 底色。
- 状态不能只靠颜色区分（如审核通过/驳回），必须同时有文字或图标。

### 2.4 禁止事项

- 禁止在组件里新写十六进制色值。确需新颜色时，先加到 `tokens.scss` 并在本文档登记。
- 禁止使用纯黑 `#000`、Element Plus 默认蓝 `#409eff`、高饱和荧光色。
- 禁止使用暗色主题配色。本项目目前只有浅色纸张主题。
- 半透明色统一以墨棕 `rgb(58 36 24 / N%)` 为基色，不用 `rgb(0 0 0 / N%)`。
- 白色只用于拍立得相框边（`#fff`）和朱红按钮文字（`#fff5f2`），其他“白底”一律用 `--zine-paper-card`。

## 3. 字体

### 3.1 字体族

| 令牌                                                 | 字体                         | 用途                                       |
| ---------------------------------------------------- | ---------------------------- | ------------------------------------------ |
| `--ft-font-family-title`（`--zine-title-font`）      | Noto Serif SC 700/900        | 页面标题、区块标题、卡片标题、评分章、序号 |
| `--ft-font-family`（`--zine-body-font`）             | Noto Sans SC 400/500/700/900 | 正文、表单、按钮、导航                     |
| `--ft-font-family-note`（`--zine-handwriting-font`） | Ma Shan Zheng（马善政毛笔）  | 手写批注、副标语、印章按钮、手写链接       |

字体通过 Google Fonts 在 `global.scss` 中加载，并带系统回退（PingFang SC、Microsoft YaHei、KaiTi）。

移动目录优先展示名称和查找入口：档口卡片以80px缩略图配文字横排，缺图时不保留空图片区。食堂缺封面时用紧凑文字标题；菜品缺图时缩短占位，保留上传与图册入口。说明、搜索计数和错误文案使用正文字体；移动端装饰图不得进入正文区域。

使用规则：

- 衬线标题字只用 700 或 900 字重，不用常规字重。
- 手写字只用于短句（建议 ≤ 20 字），不用于正文段落、表单标签、表格和错误提示。
- 一个卡片内最多同时出现两种字体族。

### 3.2 字号阶梯

| 令牌                 | 值                         | 用途                       |
| -------------------- | -------------------------- | -------------------------- |
| `--ft-font-size-xs`  | 12px                       | 芯片、标签、角标、时间戳   |
| `--ft-font-size-sm`  | 14px                       | 辅助说明、表单标签、元信息 |
| `--ft-font-size-md`  | 16px                       | 正文基准（body）           |
| `--ft-font-size-lg`  | 20px                       | 小标题、手写批注下限       |
| `--ft-font-size-xl`  | 32px                       | 页面二级标题               |
| `--ft-font-size-2xl` | `clamp(52px, 10vw, 116px)` | 首页 Hero 大字             |

常用场景值：

- 区块标题 `.section-title`：`clamp(30px, 4.2vw, 50px)`，900，行高 1.2
- 区块序号 `.section-rule__index`：`clamp(32px, 5vw, 62px)`，镂空描边印章红
- 卡片标题：桌面 30px（`--zine-card-title-size`），≤520px 降到 25px
- 手写批注：桌面 22px（`--zine-card-note-size`），≤520px 降到 18px
- 印章/贴纸文字：12–13px，700–800，字间距 0.08em

### 3.3 行高与字距

- 正文行高 1.65，移动端 1.58；标题行高 0.9–1.2，字号越大行高越小。
- 正文字距 0.01em，移动端为 0。印章、贴纸等大写短标签用 0.08em。
- 正文启用 `text-wrap: pretty`，移动端改回 `auto`。
- 长文本（店名、昵称）必须处理溢出：单行用 `text-overflow: ellipsis`，多行用 `overflow-wrap: anywhere`。

### 3.4 移动端字号

- 标题不要用纯 `vw`，统一用 `clamp()` 并给出上下限。移动端大标题控制在 34–44px。
- `input`、`select`、`textarea`、`button` 在 ≤768px 下字号固定 16px，避免 iOS 聚焦自动放大。
- 正文不小于 14px，辅助信息不小于 12px。

## 4. 间距

### 4.1 间距阶梯

以 8px 为基础单位：

| 令牌           | 值   | 典型用途                       |
| -------------- | ---- | ------------------------------ |
| `--ft-space-1` | 8px  | 图标与文字、标签之间           |
| `--ft-space-2` | 16px | 卡片内元素、表单项之间         |
| `--ft-space-3` | 24px | 卡片与卡片、区块内分组         |
| `--ft-space-4` | 32px | 双栏布局列间距、桌面页面内边距 |
| `--ft-space-5` | 40px | 区块之间                       |
| `--ft-space-6` | 48px | 大区块之间、页面顶部留白       |

允许的补充值：4px、6px、10px、12px、14px，仅用于紧凑组件内部（芯片、印章、按钮内边距）。不允许出现 7px、13px、17px 这类无规律值，旧代码修改时顺手收敛。

### 4.2 移动端间距

- 页面左右内边距：`--zine-page-padding-mobile`（14px）
- 区块间距：`--app-mobile-section-gap`（20px）
- 卡片内边距：`--app-mobile-card-padding`（16px）
- 移动端整体节奏为 12 / 16 / 20px。

## 5. 形状、描边与阴影

### 5.1 圆角

| 令牌                  | 值    | 用途                               |
| --------------------- | ----- | ---------------------------------- |
| 无圆角                | 0     | 默认：卡片、按钮、输入框、纸张容器 |
| `--ft-radius-sm`      | 4px   | 小标签、缩略图                     |
| `--zine-radius-paper` | 5px   | 便签纸、贴纸                       |
| `--ft-radius-md`      | 10px  | 弹窗                               |
| `--ft-radius-lg`      | 16px  | 仅限移动端底部抽屉、大面板         |
| `--ft-radius-pill`    | 999px | 芯片 `.zine-chip`、印章按钮        |
| `50%`                 | 圆形  | 头像、评分章、日期章               |

手账风格以直角为主。卡片和按钮不加圆角，这是与通用 UI 区分的关键。

### 5.2 描边

- 标准描边：`1px solid var(--ft-color-secondary)`，用于卡片、按钮、输入框。
- 弱描边：`1px solid rgb(58 36 24 / 11%–26%)`，用于纸张容器、分区、Tab 栏顶边。
- 虚线：`1px dashed rgb(58 36 24 / 22%–34%)`，用于标签、列表分隔、印章内框。
- 双线：`3px double`，只用于评分章。
- 分隔线可用虚线渐变：`repeating-linear-gradient(90deg, 墨棕 0 12px, transparent 12px 19px)`。

### 5.3 不规则边缘

- 撕纸边：`.torn-edge`（顶部锯齿 `clip-path`），用于顶栏、空状态卡片。
- 波浪边：`.app-page` 顶部 SVG mask，高度 `clamp(24px, 3.2vw, 38px)`，固定高度不随容器拉伸。
- 多边形图片：`clip-path: polygon(...)` 做轻微不规则裁切（如 `.dish-card__image.is-polygon`）。
- 拍立得：`7px solid #fff` 边框，底边 24px。

`clip-path` 会裁掉 `box-shadow` 和 focus 外框，需要投影或焦点时套一层外包元素。

### 5.4 阴影

本项目阴影是“实色硬投影”，模拟纸片叠放，不用模糊阴影：

| 级别     | 写法                                                   | 用途                            |
| -------- | ------------------------------------------------------ | ------------------------------- |
| 按钮     | `2px 2px 0 var(--ft-color-secondary)`                  | `.button-ink`、选中 Tab         |
| 贴纸     | `2px 2px 0 rgb(58 36 24 / 50%)`                        | `.sticker`                      |
| 卡片静止 | `3px 3px 0 rgb(58 36 24 / 12%–18%)`                    | 菜品卡、档口卡                  |
| 卡片悬停 | `4px 4px 0` 到 `5px 5px 0`，`rgb(58 36 24 / 22%–30%)`  | 配合 `translate(-2px, -2px)`    |
| 纵向层级 | `--ft-shadow-sm/md/lg`（`0 6/10/14px 0`）              | 堆叠纸张、大面板                |
| 移动端   | `--app-mobile-shadow`（`0 4px 0 rgb(58 36 24 / 10%)`） | ≤768px 所有卡片和按钮统一用此值 |

规则：

- 偏移量 x、y 相等或 y 略大（光源固定在左上）。
- 阴影颜色只用墨棕，透明度 10%–50%。
- 模糊阴影只允许用在两处：纸张容器（`0 18px 48px`）和移动端 Tab 栏（`0 -8px 22px`）。
- 新增阴影优先复用上表的值，不要再造新的偏移组合。

## 6. 纹理与装饰

### 6.1 纹理

- 牛皮纸：`--zine-texture-kraft`（600px 平铺）
- 颗粒噪点：`--zine-texture-grain`，body 伪元素，`mix-blend-mode: multiply`，透明度 0.28
- 纹理只在 body 和 `.app-page` 层出现，组件内不再叠加纹理。

### 6.2 装饰素材

素材均放在 `src/assets/images/decoration/`，通过 `tokens.scss` 中的 `--zine-decor-*` 变量引用，组件内不直接写图片路径：

| 类型     | 变量                                                 | 用法                           |
| -------- | ---------------------------------------------------- | ------------------------------ |
| 纸胶带   | `--zine-decor-tape-red`、`--zine-decor-tape-blue`    | 区块标题左上角、卡片顶部“贴住” |
| 印章     | `--zine-decor-stamp-round/recommend/premium/chinese` | 桌面两侧、推荐/精品标记        |
| 便利贴   | `--zine-decor-sticky-note`、`-alt`                   | 桌面留白处                     |
| 手绘美食 | `--zine-decor-food-sketch` ~ `-5`                    | 背景点缀                       |
| 涂鸦     | `--zine-decor-arrow`、`--zine-decor-wow`             | 指向重点内容                   |
| 其他     | `paper-clip`、`postage`、`torn-edge`                 | 卡片别针、邮票齿边、撕纸       |

### 6.3 装饰使用规则

- 装饰元素一律 `aria-hidden="true"`、`pointer-events: none`，用 `background` 或伪元素实现，不用 `<img>`。
- 透明度：背景级 `--zine-decor-opacity-bg`（0.38），安静级 `--zine-decor-opacity-quiet`（0.22），前景胶带 0.54–0.72。
- 装饰统一 `mix-blend-mode: multiply`，让素材融进纸张。
- 每个区块最多 1–2 个装饰，一屏不超过 5 个。
- 装饰不能压在文字、按钮、输入框上。放不下时宁可去掉。
- ≤768px 隐藏 `.desk-decor` 和顶栏装饰；卡片上的胶带、印章贴纸在移动端去掉或缩小到不影响内容。

### 6.4 旋转

- 卡片：±0.3°–1.2°（`--zine-rotate-left: -1.2deg`、`--zine-rotate-right: 1.1deg`）
- 贴纸：±1°–3°（`.sticker--r-2` ~ `.sticker--r3`）
- 印章：-4° 到 -8°（`--zine-rotate-stamp: -8deg`）
- 背景装饰：±7°–14°
- 同一行相邻卡片旋转方向交替，避免整排同向倾斜。
- 含正文、表单、表格的容器不旋转。
- ≤768px 全部 `transform: none`。

## 7. 组件规范

优先复用 `global.scss` 里的通用类；同类样式在两个以上页面出现时，提取为通用类或组件。

### 7.1 按钮

| 类型     | 写法                                          | 场景                                                       |
| -------- | --------------------------------------------- | ---------------------------------------------------------- |
| 主按钮   | `.button-ink.is-primary`                      | 提交、确认、发布。朱红实底，`#fff5f2` 文字                 |
| 次按钮   | `.button-ink`                                 | 取消、返回、普通操作。米白底，墨棕描边和硬投影             |
| 印章按钮 | `.button-ink.is-stamp-red` / `.is-stamp-blue` | 点赞、收藏、打卡等趣味操作。胶囊形，手写字体 19px，无投影  |
| 手写链接 | `.zine-hand-link`                             | “查看更多”“去评价”等弱操作。虚线下划线，悬停变红并变波浪线 |

规则：

- 内边距 10px 18px，字重 700。移动端最小高度 44px，≤520px 宽度 100%。
- 悬停：`translate(-2px, -2px)` + 投影加大到 `4px 4px 0`。按下：回到原位，底色可换为 `--ft-color-surface-ink`。
- 禁用：透明度 0.5，`cursor: not-allowed`，取消悬停位移。
- 危险操作（删除、驳回）使用描边样式 + 朱红文字，并且必须二次确认。
- 按钮文字 2–6 字，动词开头，如“提交点评”“上传菜品”。

### 7.2 卡片

通用结构：`1px` 墨棕描边 + 米白底（`--ft-color-surface` 或 `--zine-paper-card`）+ 10–16px 内边距 + 网格纵排，内部间距 8–10px。

- 图片在上，宽度 100%，`object-fit: cover`。桌面固定高度（菜品卡 200px），移动端用 `aspect-ratio: 16 / 10`。
- 图片风格三选一：硬边框 `is-hard`、不规则裁切 `is-polygon`、拍立得 `is-polaroid`。同一列表内保持一种。
- 标题衬线 900，价格墨棕 800，评分/评语用朱红，元信息用辅助色 14px。
- 可点击卡片加 `is-clickable`：`cursor: pointer` + 悬停上移和投影加大。可点击卡片必须是 `<a>`/`<button>` 或带 `role` 与键盘事件。
- 可选倾斜 `is-tilt`（-1°），移动端取消。

### 7.3 标签、贴纸、印章

| 组件     | 类名                 | 用途                                                 |
| -------- | -------------------- | ---------------------------------------------------- |
| 芯片     | `.zine-chip`         | 口味、类别等筛选标签。胶囊形，12px，半透明米白底     |
| 虚线标签 | 卡片内 `__tag`       | 卡片上的属性标签，1px 虚线，12px                     |
| 贴纸     | `.sticker`           | 分类角标、“NEW”。描边 + 硬投影 + 小旋转              |
| 方印     | `.stamp`             | 状态（招牌、热门、待审核）。红色描边 + 虚线内框，-4° |
| 评分章   | `.zine-rating-stamp` | 评分数字。54px 圆形双线红章                          |
| 日期章   | `.zine-date-stamp`   | 日期。72px 圆形虚线蓝章，手写字体                    |

一张卡片上印章和贴纸合计不超过 2 个。

### 7.4 表单

- 标签在上、输入框在下，纵向间距 6px；表单项之间 16px。
- 标签用辅助色 14px，必填项在标签末尾加朱红 `*`。
- 输入框：`1px solid` 墨棕描边，`--zine-paper-card` 底色，内边距 12px 14px，直角，字体继承。
- 聚焦：描边换为 `--ft-color-primary`，并保留可见焦点环（见 8.3），不允许只写 `outline: none`。
- 错误：描边换为 `--zine-stamp-red`，下方显示 `--zine-stamp-red` 色的错误文字，说明原因和修正方法。
- 占位文字用辅助色，不能代替标签。
- 评分输入用 `StarRatingInput` 组件，不另造。

### 7.5 导航

- 桌面顶栏：sticky，高度至少 82px，`rgb(242 239 230 / 94%)` 底，底边 1px 墨棕，带撕纸边。左侧品牌（衬线 34px 标题 + 手写 18px 副标语），中间导航，右侧账号。
- 导航项：最小高度 48px，带两位数序号；选中态文字和描边变朱红。
- 移动端（≤980px）：顶栏缩到 64px，只留品牌和账号；主导航移到底部 Tab 栏。
- 底部 Tab 栏：fixed，高度 `--app-mobile-tabbar-height`（72px）+ 安全区，米白渐变底 + `backdrop-filter: blur(8px)`，每项最小高度 54px，选中态朱红。
- 登录/注册页不显示导航和 Tab 栏。
- 新增导航入口时，桌面导航和底部 Tab 栏需同时检查。

### 7.6 弹窗与气泡

- 弹窗：米白纸张底，1px 墨棕描边，圆角 `--ft-radius-md`，遮罩用 `rgb(58 36 24 / 40%)` 左右。z-index 1000。
- 弹窗在窄屏下左右至少留 14px，最大高度 `calc(100vh - 48px)`，内容区内部滚动；表单改单列。
- 弹窗需要 Esc 关闭、焦点进入弹窗并在关闭后回到触发元素。
- 下拉气泡（如顶栏消息预览）：米白底 + 墨棕描边 + 顶部胶带装饰，悬停或 `:focus-within` 时显示，移动端不显示。

### 7.7 列表与表格

- 列表项用 1px 虚线分隔，最后一项无分隔线。
- 排行榜前三名用金、银、铜色的 `-soft` 底 + 实色描边，其余名次用墨棕。
- 后台表格优先在移动端改为卡片列表；无法改造时必须放在横向滚动容器内，并显示“左右滑动查看完整表格”提示。
- 表头衬线或粗体墨棕，行底交替用 `--zine-paper-card` / `--zine-paper-card-alt`。

### 7.8 空状态、加载、错误

- 空状态：撕纸边卡片（`.torn-edge`）+ 一句手写风格提示 + 一个引导操作按钮，例如“还没人点评，来当第一个”。不要只写“暂无数据”。
- 加载：在内容原位置显示占位，文案用短句（“正在翻食堂菜单…”），避免页面跳动。
- 错误：说明发生了什么和下一步怎么做，提供“重试”按钮，文字用 `--zine-stamp-red`。
- 提交成功等轻反馈用 Toast，2–3 秒自动消失，不打断操作。

### 7.9 图片

- 所有内容图片设置 `object-fit: cover` 和固定比例或固定高度，避免布局抖动。
- 菜品图默认 16:10，食堂图 4:3，头像 1:1。
- 图片需要有意义的 `alt`（如菜品名）；装饰图用 CSS 背景，不写 `alt`。
- 图片缺失或加载失败时显示默认占位图（后端 `data/default_img/` 提供），不留空白框或破图图标。目前前端尚未统一处理 `@error`，新组件需要补上。
- 首屏以外的图片加 `loading="lazy"`。

## 8. 动效与交互

### 8.1 时长与缓动

| 令牌                   | 值                                     | 用途                 |
| ---------------------- | -------------------------------------- | -------------------- |
| `--ft-transition-fast` | 180ms `cubic-bezier(0.37, 0, 0.63, 1)` | 悬停、按下、颜色变化 |
| `--ft-transition-base` | 320ms `cubic-bezier(0.22, 1, 0.36, 1)` | 展开、弹窗、卡片入场 |

- 过渡只作用于 `transform`、`box-shadow`、`opacity`、`color`、`background`、`border-color`，不对 `width`、`height`、`top` 做动画。
- 禁止使用 `transition: all`。
- 悬停效果包在 `@media (hover: hover)` 内，避免触屏上“粘住”。

### 8.2 自动滚动与轮播

- 首页轮播的自动横向滚动在触摸设备上暂停，由 `useAutoHorizontalScroll` 处理，不要在组件里另写定时器。
- 鼠标悬停、获得焦点时暂停自动滚动。
- 拖拽滚动使用 `useDragScroll`。

### 8.3 焦点

- 所有可交互元素必须有可见焦点样式。统一写法：

```scss
&:focus-visible {
  outline: 2px dashed var(--ft-color-primary);
  outline-offset: 3px;
}
```

- 用 `:focus-visible` 而不是 `:focus`，鼠标点击时不显示，键盘操作时显示。
- 带 `clip-path` 的元素，焦点环加在外层包裹元素上。

### 8.4 减少动效

用户开启“减少动态效果”时，关闭位移动画和自动滚动：

```scss
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    transition-duration: 0.01ms !important;
    animation-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

## 9. 移动端规范汇总

- 触控目标不小于 44 × 44px，Tab 栏项不小于 54px 高。
- 输入控件字号 16px。
- 去掉所有旋转、负 margin、绝对定位贴纸和大投影；阴影统一 `--app-mobile-shadow`。
- 页面底部预留 Tab 栏高度 + `env(safe-area-inset-bottom)`。
- 按钮组改单列或两列网格。
- Hero 区改为紧凑欢迎区，不占满首屏。
- 每个新页面至少在 390 × 844 和 360 × 740 两个视口下检查：无横向溢出、无文字重叠、按钮可点。

## 10. 无障碍

- 文字对比度满足 2.3 节要求，正文至少 4.5:1，大字至少 3:1。
- 使用语义标签：导航 `<nav>` 并带 `aria-label`，主内容 `<main>`，可点击元素用 `<button>` 或 `<a>`，不用 `<div @click>`。
- 图标按钮必须有 `aria-label`。
- 评分、状态等信息不只靠颜色或图形表达，需要有文字。
- 表单输入都要有关联的 `<label>`，错误信息通过 `aria-describedby` 关联到输入框。
- 装饰元素 `aria-hidden="true"`。
- 以上是设计层面的最低要求。完整的 WCAG 合规需要配合屏幕阅读器等辅助技术实测和专业无障碍评审。

## 11. Element Plus 使用约定

`element-plus` 已在依赖中，但目前没有在 `main.js` 注册，页面也未使用其组件。若后续引入（如表格、日期选择、上传），必须先覆盖主题变量，让它融入手账风格：

```scss
:root {
  --el-color-primary: var(--ft-color-primary);
  --el-color-danger: var(--ft-color-danger);
  --el-color-success: var(--ft-color-accent);
  --el-text-color-primary: var(--ft-color-text);
  --el-text-color-regular: var(--ft-color-secondary-soft);
  --el-border-color: var(--ft-color-secondary);
  --el-bg-color: var(--zine-paper-card);
  --el-border-radius-base: 0;
  --el-font-family: var(--ft-font-family);
}
```

主题覆盖统一放在 `src/assets/styles/` 下的独立文件中（例如 `element-theme.scss`），由 `global.scss` 引入。不允许出现 Element Plus 默认蓝色和默认圆角。

## 14. 安卓端参考说明

本节说明开发安卓端时，本文档哪些内容可以沿用，哪些需要换成安卓的写法，哪些不适用。目标是让安卓端和 Web 端看起来是同一个产品。

如果安卓端是 WebView 套壳或 Capacitor 这类混合方案，直接复用 Web 代码，本文档按第 9 节“移动端规范”执行即可，以下内容主要针对原生开发（Jetpack Compose 或 View 体系）。

### 14.1 可直接沿用

| 内容               | 章节     | 说明                                                                                                                       |
| ------------------ | -------- | -------------------------------------------------------------------------------------------------------------------------- |
| 风格定位           | 1        | 手账、硬边、印章、纸胶带的整体方向不变，按移动端（App 化）那一档执行                                                       |
| 色板与色值         | 2.1      | 色值原样搬到 `colors.xml` 或 Compose `Color` 常量，令牌名保持对应（如 `ft_color_primary`）                                 |
| 用色比例、禁止事项 | 2.2、2.4 | 规则不变。安卓同样不用纯黑、不用 Material 默认紫/蓝、不做暗色主题                                                          |
| 对比度结论         | 2.3      | 与平台无关，直接适用                                                                                                       |
| 字体族与使用规则   | 3.1      | 三种字体都在 Google Fonts，可打包进 `res/font` 或用可下载字体                                                              |
| 间距阶梯           | 4.1、4.2 | 8 的倍数体系与安卓 8dp 网格一致，数值按 1px = 1dp 换算                                                                     |
| 圆角               | 5.1      | 直角为主、胶囊和圆形的用法不变                                                                                             |
| 装饰素材与使用规则 | 6.2、6.3 | `src/assets/images/decoration/` 的 PNG 可直接复用，建议转 WebP 放入 `res/drawable-nodpi`。数量、透明度、不挡内容的规则不变 |
| 组件的视觉规则     | 7.1–7.9  | 按钮层级、卡片结构、印章/贴纸、表单、空状态文案、图片比例都适用                                                            |
| 移动端规范         | 9        | 除浏览器专属条目外基本都适用，是安卓端最主要的参照                                                                         |
| 无障碍原则         | 10       | 原则适用，实现方式不同（见 14.2）                                                                                          |

### 14.2 需要转换写法

| Web 写法                             | 安卓对应                                                                                                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 字号 `px`                            | 文字用 `sp`（跟随系统字体缩放），按 1px = 1sp 换算；布局尺寸用 `dp`                                                            |
| `clamp()` 响应式字号                 | 安卓按固定档位取值：大标题 34–40sp，区块标题 26–30sp，卡片标题 22–25sp，正文 15–16sp                                           |
| 硬投影 `box-shadow: 3px 3px 0`       | 安卓 `elevation` 只有模糊阴影，不能用。改为在卡片后方绘制一个偏移的墨棕色块（Compose 用 `drawBehind` 或两层 `Box` + `offset`） |
| 移动端阴影 `--app-mobile-shadow`     | 卡片下方 4dp 偏移、10% 墨棕的实色块，做法同上                                                                                  |
| `mix-blend-mode: multiply`           | Compose 用 `BlendMode.Multiply`；View 用 `PorterDuff.Mode.MULTIPLY`                                                            |
| `clip-path` 撕纸边、不规则图片       | Compose 用 `GenericShape` 自定义 `Shape`；View 用 `Path` 裁剪或直接用切好的图片                                                |
| 牛皮纸纹理、噪点                     | 把 SVG 纹理导出为位图，作为 `BitmapShader` 平铺背景，透明度同 Web                                                              |
| 过渡曲线 `cubic-bezier(...)`         | Compose `CubicBezierEasing(0.22f, 1f, 0.36f, 1f)`；View 用 `PathInterpolator`。时长 180ms / 320ms 不变                         |
| 底部 Tab 栏                          | 用 `NavigationBar` 或自定义底栏，选中态朱红，背景米白，去掉 Material 默认的指示器胶囊色                                        |
| 安全区 `env(safe-area-inset-bottom)` | `WindowInsets.navigationBars` / `systemBars`，开启 edge-to-edge 后自行处理内边距                                               |
| 弹窗、Toast                          | 用 `Dialog` / `ModalBottomSheet` / `Snackbar`，但要覆盖成米白底、墨棕描边、直角或 10dp 圆角                                    |
| `aria-label`、`aria-hidden`          | `contentDescription`；装饰元素设 `contentDescription = null` 或 `importantForAccessibility="no"`                               |
| `<label>` 关联输入框                 | `TextField` 的 `label` 参数或 `labelFor`                                                                                       |

使用 Material 3 组件时，先在主题里把 `colorScheme`（primary、error、surface、background、onSurface 等）映射到第 2 节的色值，把 `shapes` 设为直角，把 `typography` 换成第 3 节的字体，做法与第 11 节覆盖 Element Plus 主题相同。

### 14.3 安卓端的不同要求

- 触控目标不小于 48 × 48dp（安卓规范），比 Web 的 44px 略大，以安卓为准。
- 正文不小于 14sp，并在系统字体放大到 1.3 倍时检查是否截断或重叠。
- 返回操作走系统返回键/手势，不在页面上单独放“返回”按钮作为唯一出口。
- 状态栏颜色与顶栏一致，用米白 `#f2efe6`，图标用深色。
- 手写字体文件较大（Ma Shan Zheng 约数 MB），如果包体积敏感，改为可下载字体或只在首页标语等少数位置使用。
- 减少动效：读取系统“移除动画”设置（`Settings.Global.ANIMATOR_DURATION_SCALE` 为 0 时），关闭位移动画和自动轮播。

### 14.4 不适用

| 内容                                      | 章节        | 原因                                                                                                 |
| ----------------------------------------- | ----------- | ---------------------------------------------------------------------------------------------------- |
| 桌面端装饰、两侧留白、旋转角度            | 6.3、6.4    | 安卓端按移动端执行，不做旋转、不放桌面装饰                                                           |
| 悬停效果、`@media (hover: hover)`         | 7.1、8.1    | 触屏无悬停，按下态用颜色加深（`--ft-color-surface-ink`）和水波纹/缩放反馈代替                        |
| `:focus-visible` 写法                     | 8.3         | 安卓有自己的焦点系统，只需保证外接键盘和无障碍焦点可见                                               |
| 自动横滚组合式函数                        | 8.2         | `useAutoHorizontalScroll` 等是 Vue 代码，安卓用 `HorizontalPager` 等重新实现，保留“触摸时暂停”的规则 |
| 输入框 16px 防缩放、横向溢出、`text-wrap` | 3.3、3.4、9 | 浏览器专属问题                                                                                       |
| Element Plus 约定                         | 11          | Web 组件库                                                                                           |
| 现状偏差、提交前自检清单                  | 12、13      | 针对 Web 代码库。安卓端应另建自己的偏差表和自检清单                                                  |
