# 作者修改食记

`CommunityPostEdit` 只负责本人入口及编辑器开关，两种详情展示共用；`PostCreateModal` 通过 `editPost` 参数复用标题、正文、照片与菜品选择。修改经独立 `editCommunityPost` API 提交，不读写或删除原有本机发帖草稿。

打开时保存所见 `contentRevision`。提交整帖替换，保留请求编号和已上传引用以重试失败；改动载荷后更换编号。服务器版本冲突时保留输入并阻止旧内容再次提交，用户确认后才读取最新内容，随后可重新编辑。切号／关闭／卸载组件均使在途结果失效，旧上传不能继续关联。

成功后重新读取同一帖子，并使发现／关注／收藏／我的缓存失效；读取失败不继续展示原来的公开操作状态。待审核预览隐藏公开评论和互动入口，详情标注修改时间，原发布时间不变。全屏图片预览的公开互动上下文仅向已公开帖子提供。

人工审核提交完整详情所见 `contentRevision`，避免审核旧内容时误通过作者刚提交的新版本。置顶列表与权限管理仍用独立组件及接口，编辑器不拥有置顶管理逻辑。

编辑弹窗保持手账样式，窄屏内部滚动，关闭按钮至少 44px。自动化覆盖失败重试、上传复用、切号、版本冲突和独立发帖草稿；浏览器另验证实际详情入口和帖子弹窗内的编辑。后端 V57 必须先于客户端升级，本说明不授权部署。
