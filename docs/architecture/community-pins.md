# 社区置顶

发现无搜索条件时，独立 `CommunityPins` 紧凑列表展示最多 3 条标题和作者；普通图文流排除相同置顶。关注、搜索、作者页、收藏和我的保持原规则。`CommunityPinManager` 从独立 API 获取管理快照，可保留隐藏名额、完整排序及取消，能力由服务器 `community.pin.manage` 提供，默认超管。

发现响应的 `pins` 与普通 `items/total/cursor` 处于同一读取快照。加载下一页带 `pinRevision`，收到 `PIN_SET_CHANGED` 后替换为新第一页，不静默丢项或重复追加。管理版本冲突需手动刷新后操作；写入期间锁定操作，切号关闭旧弹窗并丢弃在途结果。原帖 ID、发布时间、计数和关系不变。

仅已公开帖子可新增置顶；待审核／被拒保留名额及顺序但用户不可见，审核通过恢复；删除或下架释放名额。作者编辑使用独立[编辑器契约](community-post-edits.md)，与置顶管理分开。后端 V56 需先于客户端部署，本文不授权发布或部署。
